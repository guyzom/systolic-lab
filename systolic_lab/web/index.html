For a tile of h × w outputs: operand bytes = K(h + w), output bytes = 4hw, compute cycles = K + h + w − 2. Each transaction takes setup + ⌈bytes / bandwidth⌉ cycles. Global utilization = MNK / (array rows · array columns · total cycles).

Tail tiles omit padding reads and mask unused PEs. Accumulators stay local for all K steps. Scratchpad capacity holds operands only. No reuse across output tiles, double buffering, bank conflicts, DMA contention, energy model, or TPU instruction set is modeled.
